How panel states work

One day, the site's own: the number is the reading at the latest stored slot, and never the last value carried forward. Panels are recorded during daylight, so a night gap is expected and is never drawn as 0 kW. Orange is producing now, blue worked today and stopped (shading or the sun moving on), amber has produced nothing today, and purple is not reporting while the rest of the array is — a stopped panel and a failed read look alike from here, so both are purple. Playback reads stored five-minute samples only.
